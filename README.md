# Word Shapes

A small browser game for learning basic English grammar, starting with nouns.

Open `index.html` in any browser. There is nothing to install.

- **Learn**: short lessons on nouns, common and proper nouns, plurals, verbs and adjectives.
- **Noun Hunt**: tap the nouns in a sentence. A harder level adds verbs and adjectives.
- **Sort the Nouns**: sort nouns into person, place, thing or idea, or into common and proper.
- **Plurals**: pick the correct plural, including irregular ones like *mouse → mice*.

The shapes follow the Montessori grammar symbols: a black triangle for a noun, a red circle for a verb and a small blue triangle for an adjective. Best scores are saved in your browser.
